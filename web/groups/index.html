AI-Agora · Problem 1

Forming Groups with Consent

Thresholds make sharing pay

Nimrod Talmon · Ben-Gurion University · draft, November 18, 2026

Motivation

A group exists only once enough say yes

A single yes is useless alone, but it points to where the others are.

Model

Groups with a threshold, only yes counts

\(n\) members, \(m\) initiatives. Member \(i\) accepts a set \(A_i\), unknown to all, its agent included.

An agent may ask its member at most \(b\) questions: “join \(j\) if it forms?”

Outcome: disjoint groups \(G_j\) of members who said yes to \(j\); each empty or of size at least \(k\).

Welfare: \(\sum_j |G_j|\). OPT: its maximum given all \(A_i\).

With \(k=1\): pick-one, with many options at once.

Model

Settings and measure, as before

Silos: agents ask alone, then report; a rule forms groups. With a convention: agents share a random seed fixed in advance.

Central: a coordinator sees all answers and decides who is asked what.

Grassroots: agents message each other; all output the same outcome.

Guarantee: \(\min_{\text{communities}}\ \mathbb{E}[\text{welfare}]\,/\,\mathrm{OPT}\). Gain: best central / best silos.

First case, the hidden group: exactly \(k\) members accept one hidden initiative; no one accepts anything else.

Theorem 1

Hidden group: silos need a convention

For the hidden group, the best silos guarantee is

\(\tfrac{b}{m}\) with a convention, \(\big(\tfrac{b}{m}\big)^{k}\) without one.

≥ All ask the same \(b\) random initiatives; or each its own.

≤ A no tells nothing, so questions are fixed in advance; hide the group where few ask.

\(n=8,\ m=6,\ b=2,\ k=3\); the group accepts 3.

Theorem 2

Hidden group: a gain of order \(\min(k,\,m/b)\)

If \(b \ge 2\) and \(m\) divides \(n\), then central guarantees \(1-\big(1-\tfrac{b-1}{m}\big)^{k}\). No protocol guarantees more than \(\min\big(1,\tfrac{kb}{m}\big)\).

So the gain is \(\Theta\big(\min(k,\tfrac{m}{b})\big)\); the constant is at least \(0.3\).

≥ Explore: in random order, \(b-1\) questions each, cycling; commit: all ask about the yes. ≤ Before the first yes, all answers are no; \(nb\) of \(nm\) pairs are asked, \(k\) are hits.

Simulation

Central grows with \(k\); silos do not

Hidden group: \(n=60\), \(m=12\), \(b=3\).

Related work

Closest work, and the difference

Group activity selection

Ganian, Ordyniak, Rahul 2023 (Algorithmica)

groups with size limits; full information

Stable communities from samples

Igarashi, Sliwinski, Zick 2019 (AAAI)

learns from sampled coalitions; no questions, no threshold

Elicitation for group decisions

Naamani-Dery, Golan, Kalech, Rokach 2014

few queries, but one winning item, no groups

Adaptive group elicitation

Ding et al. 2026 (arXiv)

LLM picks whom to ask; predicts answers, forms nothing

New here: a size threshold together with a question budget per member; only a yes enrolls.
