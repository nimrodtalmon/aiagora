AI-Agora

The Value of an Agora

When personal agents should share

Nimrod Talmon · Ben-Gurion University · draft, November 18, 2026

Motivation

Soon, everyone has an AI agent

Each question costs attention; no one is committed without a yes.

Model

Pick one option, ask little, only yes counts

n people, m options. Each person approves some options, unknown to everyone, its agent included.

A person’s agent may ask it at most b questions: “do you approve option o?”

Outcome: one option, with the people who said yes to it.
Welfare: their number. OPT: the most approvers of any option.

Running example: 8 people, 6 options, 2 questions each.

Model

Three settings, one measure

Silos: agents ask alone, then report; a rule picks.

Central: a coordinator sees all answers and decides who is asked what.

Grassroots: agents message each other; all output the same outcome.

Guarantee: min over communities of E[welfare] ÷ OPT.
Gain: best central ÷ best silos.

Questions (attention) and messages are counted separately.

Theorem 1

Silos guarantee exactly b/m

In silos, the best guarantee is b/m.

≥ Each agent asks b random options; the rule picks the most-yes option. Every approver of the best option is found with probability b/m.

≤ Let everyone approve one hidden option. An agent alone asks about it with probability at most b/m.

8 people, 6 options, 2 questions: 3 join (expected 2.7).

Theorem 2

Central gets everyone: a gain of m/b

If n ≥ m, b ≥ 2, and all approve one option, then central enrolls everyone. Hence the gain is m/b, the most possible.

Explore: one question per person, spread over all options; only the favorite gets a yes. Commit: everyone asks about it.

Theorem 3

No shared tastes, no gain

If only one person approves only one option, then no protocol in any setting guarantees more than b/m.

So over all communities, the gain is 1.

Until that exact pair is asked, all answers are no. Only n·b of the n·m pairs can be asked.

Theorem 4

A popular option: central nears OPT

If b ≥ 2 and some option is approved by a fraction p of the people, then central’s expected welfare is at least

(1 − O(√(m log(mn) ⁄ n(b−1)) ⁄ p)) · OPT.

For fixed m, b, p: it tends to OPT as n grows; silos stay at b/m.

Explore: ≈ n(b−1)/m random people per option estimate its popularity.

Commit: everyone asks about the leader.

Simulation: popular option 1/2, others 1/4; m = 10, b = 2.

Theorem 5

One question each: still nears OPT

If b = 1, then sampling (n/m)2/3 people per option, and asking everyone else about the leader, gives welfare that tends to OPT as n grows.

Explorers of losing options cannot join: about m·(n/m)2/3 people, a vanishing fraction.

Simulation: popular option at 1/2, 10 options.

Observation

In this model, grassroots ≥ central

For every budget, best grassroots ≥ best central: agents agree in advance that agent 1 coordinates. Same questions, same messages.

What really separates them must be added to the model: trust in one agent, load per agent, privacy, incomplete networks.

Closest work, and the difference
