The Scale Paradox

Bigger group chats form fewer groups, unless agents route

Nimrod Talmon · Ben-Gurion University · draft, November 18, 2026

Model

Initiatives that need \(k\) members

\(n\) members, activity types \(t\). A member accepts \(t\) with probability \(p_t\) (popularity), independently.

Type \(t\) has an initiator who accepts it. Its group forms if at least \(k\) reached members accept.

The initiator gains \(B\) if it forms, and pays \(c\) per reached member who does not accept (bothered). It announces iff

\(B \cdot \Pr[\text{forms}] \ \ge\ c \cdot \mathbb{E}[\text{bothered}]\)

Welfare: groups formed. The cost \(c\) is social: fear of spamming.

Model

Two channels

Broadcast: an announcement reaches all other \(n-1\) members.

Agora: each member's agent guesses whether its member accepts \(t\), wrong with probability \(\varepsilon\). The initiator's agent invites, in random order, only members guessed to accept, and stops at \(k-1\) acceptances.

Benchmark: types with at least \(k\) acceptors (viable).

Orange: accepts. In the agora, agents guess wrong once each way.

Theorem 1

Broadcast: groups rise, then vanish

In broadcast, type \(t\) is announced only if \((1-p_t)(n-1) \le \tfrac{B}{c}\).

So if all \(p_t \le \bar p < 1\), then no group forms once \(n > 1 + \tfrac{B}{c(1-\bar p)}\).

Expected bothered: \((1-p_t)(n-1)\), while \(\Pr[\text{forms}] \le 1\).

Niche types drop out first.

Theorem 2

Agora: groups keep forming as \(n\) grows

Let \(r_t\) be the chance that an invited member accepts. As \(n \to \infty\), type \(t\) forms with probability tending to 1 if \((k-1)\tfrac{1-r_t}{r_t} < \tfrac{B}{c}\); if \(>\), never announced.

\(r_t = \tfrac{p_t(1-\varepsilon)}{p_t(1-\varepsilon)+(1-p_t)\varepsilon}\).

Inviting stops at \(k-1\) yeses, so the number bothered does not grow with \(n\).

Simulation

Peak for broadcast, growth for the agora

300 types, \(p_t = \tfrac{0.5}{t}\), \(k=4\), \(\tfrac{B}{c} = 100\).

Broadcast peaks at 9 groups at 80 members, and has none from 201 on.

The agora tends to 150 and 39 groups.

Broadcast: exact. Agora: 400 runs per type.

Related work

Closest work, and the difference

Attention as a commons

Anderson & de Palma 2009 (RAND)

senders over-use readers’ attention; no groups, no size result

Niche crowding

Falkinger 2005 (IZA working paper)

larger reach raises the bar to be noticed; no groups

Critical mass

Oliver & Marwell 1988 (ASR)

larger groups reach k; the few must “find one another” — in words

Group activity selection

Darmann et al. 2018 (IJGT)

groups with lower size bounds; finding members is free

New here: threshold groups found through one channel whose cost falls on all members; the number of groups as a function of community size.
